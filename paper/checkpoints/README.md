## 后续检查点约定

- 仅在用户明确要求时建立检查点；日常编辑不自动建立检查点。
- 按 P002、P003 等顺序追加，每个检查点使用独立目录和用户指定的名称。
- 每次保存精确的修改前后文本、来源版本、作用范围和撤销补丁；保留已有检查点，不覆盖历史。
- 用户说“回退某检查点”时，先读该条记录，只撤销该检查点所记录的差异。不得用整篇旧稿替换当前正文，也不得直接回退整条分支。
- 后续修改若与检查点重叠，结合修改前、修改后和当前文本逐处合并，保留后续独立修改；不能直接覆盖整个小节。
- 回退后检查作用范围之外的内容逐字节不变，并在该检查点记录回退日期、结果和提交版本。
