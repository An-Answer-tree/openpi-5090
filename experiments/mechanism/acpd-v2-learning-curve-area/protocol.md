# ACPD-v2 训练轨迹成功率面积

预注册日期：2026-09-29。性质：已知各 checkpoint 汇总成功率后的探索性分析；
只读现有正式验证日志，不训练、不重新仿真。

## 问题

H9-Fixed 在 10K 优于匹配 SFT，但 30K 不再领先。检验从 5K 到 30K 的整个
训练过程中，H9 是否在相同优化步数下取得更高的平均闭环成功率。

## 固定分析

| 项目 | 设置 |
|---|---|
| 模型 | backview BS64 H9-Fixed 与匹配 SFT |
| checkpoint | 5K、10K、15K、20K、25K、30K；不按结果删点 |
| 数据 | 每点四套、40 任务、每任务 50 个相同初始状态 |
| 主指标 | 两条 pooled 成功率曲线在 5K–30K 的梯形面积，除以 25K 步宽；报告 H9−SFT，单位百分点 |
| 次指标 | 四套各自的面积差；10K–30K 面积差；逐任务面积差的正/负/零数量 |
| 不确定性 | 每任务对 50 个 episode 有放回抽样 10,000 次，两个模型和全部 checkpoint 使用同一组抽样索引；报告百分位 95% 区间，seed 42 |

先确认六个 checkpoint 的任务和 episode 键完全一致，且每次配对分析的两组日志
确实对应同一步。若主指标区间下界大于零，仅支持“按优化步数/样本呈现量衡量的
轨迹平均成功率更高”；不解释为最终上限、总训练耗时或 GPU 小时更优。
10K–30K 分析用于判断是否完全由最早的 5K 点驱动。

由于六个点的 pooled 成功率在制定本协议前已知，所有统计检验均为探索性，
重采样区间也不覆盖训练 seed 的变化或新任务。
