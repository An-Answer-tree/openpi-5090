# ACPD-v2 训练轨迹成功率面积：探索性结果

使用已有 backview BS64 H9-Fixed 与匹配 SFT 的 5K、10K、15K、20K、25K、30K
全量验证；每点 40 任务、每任务 50 回合。分析脚本核对了每点的配对回合、六点的
任务集合及已有汇总差值。面积为成功率曲线的梯形积分除以步数范围，单位仍是成功率。
H9 的 10K、15K、20K 来自同配置的 checkpoint 重建/续训任务，5K、25K、30K
来自原训练；因此六点是匹配配置的重建序列，**不是一条单次运行的连续轨迹**。

| 范围 | SFT 平均成功率 | H9 平均成功率 | H9−SFT | 配对回合重采样 95% 区间 |
|---|---:|---:|---:|---:|
| 5K–30K | 40.860% | 45.995% | +5.135 点 | [+4.080, +6.210] 点 |
| 10K–30K | 46.438% | 49.919% | +3.481 点 | [+2.294, +4.694] 点 |

| 套件，5K–30K | 面积差 H9−SFT | 配对回合重采样 95% 区间 |
|---|---:|---:|
| Spatial | +6.56 点 | [+4.26, +8.84] 点 |
| Object | +8.56 点 | [+6.38, +10.76] 点 |
| Goal | +2.44 点 | [+0.42, +4.48] 点 |
| LIBERO-10 | +2.98 点 | [+1.10, +4.86] 点 |

逐任务面积差为正 30/40、负 10/40。10K–30K 仍为正，说明面积优势不只由
5K 一个端点产生。但 H9 在 30K 成功率为 58.00%，低于 SFT 的 60.45%；
本结果只支持在相同优化步数/样本呈现量下，5K–30K 轨迹平均表现更高，
不支持最终成功率上限更高。历史运行至 H9 5K 约 13 小时 55 分，SFT 至10K
约 6 小时 35 分；不能将步数优势写成 GPU 时间优势。

这项分析是在已知六个 checkpoint 汇总结果后设计的探索性再分析。区间仅对固定
任务和既有 50 个回合重采样，不覆盖重建训练段与原训练段之间的运行差异，
也不覆盖重新训练的随机性；四套分项没有多重比较校正。

证据：`protocol.md`、`analyze.py`、`results/learning_curve_area.json`。输入的
六组配对验证结果路径记录在结果 JSON 的 `input_pairs` 字段。
