# ACPD-v2 两路注入的离线差异

本分析复用同 checkpoint 的四分支逐样本误差，不重新训练或仿真。
每点为 1,024 个样本、194 个 episode；指标是按 episode 等权的真实 7 维
flow MSE 差值。问题是在已看到原总体均值后提出，故结果为探索性。

| Checkpoint | wrist 单路 − agentview 单路 | 配对 95% 区间 | 完整注入 − agentview 单路 | 配对 95% 区间 |
|---|---:|---:|---:|---:|
| 10K | +0.00002726 | [+0.00000761, +0.00004680] | +0.00001826 | [-0.00000031, +0.00003635] |
| 30K | +0.00001012 | [-0.00000382, +0.00002519] | +0.00000809 | [-0.00000575, +0.00002275] |

| Checkpoint | 两路交互 MSE | 配对 95% 区间 |
|---|---:|---:|
| 10K | +0.00000094 | [-0.00001455, +0.00001617] |
| 30K | +0.00000343 | [-0.00000414, +0.00001152] |

10K 的 agentview 单路局部 MSE 低于 wrist 单路，但 30K 的相同差值区间跨零，
未达到协议要求的两点一致标准。完整注入相对 agentview 单路，以及两路交互项，
两个 checkpoint 的区间也均跨零。10K 的分路差异只占关闭注入 MSE 的约
0.022%，不能据此判断部署时 wrist 有害或现在应改用分路 gate。

这项结果只描述已训练 H9 的**推理时局部动作误差**，不区分训练期辅助目标的效果，
不测闭环成功率，且三个指标、两个 checkpoint 未做多重比较校正。10K 与 30K
属于不同训练运行，不能把数值变化归因于训练进度。

协议：`view-branch-protocol.md`。原始输入和精确数值：
`view-branch-results.json`；分析脚本：
`scripts/distillation_acpd/analyze_gate_views.py`。
