# 可观测视角一致性与 gate 可靠性诊断

预注册日期：2026-09-29。性质：冻结 checkpoint 的单卡离线诊断；不训练、不仿真，
不移动 checkpoint 或数据集。

## 问题

已有 oracle 分析使用真实 flow target 判断 contribution 注入方向是否正确，但真实
target 在推理时不可见。本实验检查 student 自己能看到的量，是否能预测完整注入相对
关闭注入的局部动作误差是下降还是上升。

## 做法

复用 H9 10K 和 30K gate probe 的固定数据、噪声和四个前向分支。除原有速度改变量
外，保存三个不使用真实 target 的量：

1. agentview 与 wrist 两路动作改变量的 cosine；
2. 两路改变量的分歧度 `||a-w||/(||a||+||w||)`；
3. 两路改变量的幅度不平衡度 `| ||a||-||w|| |/(||a||+||w||)`。

以 episode 为单位，把完整注入相对关闭注入的 flow MSE 是否下降作为离线标签。按
episode 奇偶做两折交叉验证，只在训练折决定特征方向，在留出折报告 AUROC。特征只
使用模型预测，真实 flow target 只用于生成离线诊断标签。

## 判据

若同一特征在 10K 和 30K 的两个留出折平均 AUROC 均高于 `0.60`，且方向一致，
则说明存在低成本的可观测可靠性信号，值得继续做 held-out episode 的动态 gate。
否则不提交动态 gate 训练，避免把 oracle 相关性误认为可部署信号。

该实验只能证明“能否预测离线局部 MSE 方向”，不能直接证明仿真成功率提升。
