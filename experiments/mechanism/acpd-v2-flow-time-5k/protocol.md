# 5K Flow 时间段误差诊断

预注册日期：2026-09-28。性质：探索性、只读诊断；不训练模型，不验证任务成功率。

## 研究问题

H9-Fixed 与匹配 SFT 的训练 flow MSE 几乎重合，但 5K 成功率相差 `9.30` 点。
平均 MSE 可能掩盖不同时间段的误差分布。两组训练均使用
`t ~ Beta(1.5, 1)`；推理按若干时间点积分。时间采样影响 flow 模型训练的
现象已有研究，但图像生成的结论不能直接套用于本任务：
<https://arxiv.org/abs/2603.12517>、<https://arxiv.org/abs/2405.20320>。

## 固定诊断

| 项目 | 设置 |
|---|---|
| 模型 | backview SFT BS64 5K；H9-Fixed BS64 5K 恢复轨迹 checkpoint |
| 数据 | 原 fixed_dataset；两模型读取完全相同的样本、动作与图像 |
| 输入 | 每个样本使用相同高斯噪声；时间固定为 `0.1/0.3/0.5/0.7/0.9`，按样本轮换 |
| 预算 | `debug01` 单卡；BS8，64 batch，共 512 次成对前向 |
| 主观测量 | 每个时间段实际 7 维动作的 paired MSE 差值 `H9-SFT` |
| 辅助观测量 | 32 维整体 MSE；逐样本误差与 episode ID |

先校验两模型的动作目标、时间和 episode 序列完全相同；不匹配则不比较。
每个时间段报告样本数、两组均值、配对差值和 episode-cluster bootstrap
95% 区间。结果仍是训练数据上的离线拟合诊断，不是独立验证集，也不对应闭环成功率。

## 决策规则

只有当某时间段的误差明显高于其余时间段，且相同时间段的 H9/SFT 差异
方向稳定，才将“调整时间采样”列为后续训练候选。即使出现该现象，也不能
直接断言重采样会提高成功率；下一阶段需要等预算允许时开展单变量训练消融。
若各时间段误差和差异都接近，则不投入时间采样实验。

## 排除的候选

此前提出的“只保留教师修正中朝真实目标方向的部分”不作为本轮 GPU 实验。
令 `e = u - v_s`、`d = v_t - v_s`，则 `d` 在 `e` 方向的投影为
`(d·e / ||e||²)e`。平方 flow 损失对输出的梯度正比于 `-e`，因此只用
该投影得到的新增更新，等价于对真实 flow 监督施加样本权重，不能单独证明
教师提供了新的动作信息。偏离 `e` 的分量在当前输出处与 flow 梯度正交，
不能一阶加快该样本的 flow MSE 收敛。教师的长期表征作用仍是开放问题。
