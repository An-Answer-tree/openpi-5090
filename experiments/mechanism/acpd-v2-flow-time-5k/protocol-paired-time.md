# 同样本全时间点复核

预注册日期：2026-09-28。首轮 `136591` 发现 `t=0.1` 时 H9-Fixed 的训练集
flow MSE 高于 SFT；本复核在看到首轮结果后设计，属于探索性复核，
不是独立确认性试验。

| 项目 | 固定设置 |
|---|---|
| 模型与数据 | 与首轮相同的冻结 5K checkpoint、fixed_dataset 和 backview 样本变换 |
| 样本 | 新 seed=43，BS8 × 16 batch，共 128 个样本 |
| 时间 | 每个样本、同一高斯噪声，分别计算 t=0.1/0.3/0.5/0.7/0.9 |
| 资源 | debug01 单卡，8 CPU，24G；不训练、不写 checkpoint |
| 主要复核量 | t=0.1 实际 7D 动作 MSE 差值 H9-Fixed 减 SFT，episode-cluster bootstrap 双侧95%区间 |
| 次要量 | 同一样本跨时间点的 MSE 轨迹和整体差值；仅作探索性描述 |

若主要差值的区间仍全大于零，认为低 t 段的训练集离线误差方向在
另一批采样/噪声下得到复现；否则不将首轮单时间段差异视为稳定现象。
即使复现，也不能推断更改时间采样会提高仿真成功率。
