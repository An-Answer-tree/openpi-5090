# ACPD-v2 中期逐任务差异复核

预注册日期：2026-09-29。性质：在已看到四套汇总差异后的探索性分析，
只读现有 LIBERO 验证日志，不训练、不重复仿真。

## 问题

H9-Fixed 相对 SFT 在 20K--30K 的 Object 差值保持为正，Goal 差值保持为负。
检查这些套件差异是否由少数任务造成，以及同一任务的差异方向能否跨 checkpoint 保持。

## 数据与指标

| 项目 | 固定设置 |
|---|---|
| 模型 | H9-Fixed 与匹配 backview SFT 的20K、25K、30K |
| 数据 | 四套，每套10任务，每任务50个相同初始状态；解析已有验证日志 |
| 逐任务指标 | 每个step、任务的成功率差 `H9-SFT` |
| 主要描述 | 每套三个step中正差/负差的任务数；跨三个step同号的任务数 |
| 次要描述 | 20K与30K的逐任务差值 Spearman 相关；绝对差值最大的任务 |

若某套仅有一两个任务产生大差异，则不据套件均值设计统一 task gate；
若多个任务在三个step同向，可将任务条件化作为后续训练候选。
由于同一训练seed、同一任务集合和相同初始状态，跨step的一致性不是独立复现。
逐任务分析涉及40个比较，不用单任务未校正区间声称显著性。
