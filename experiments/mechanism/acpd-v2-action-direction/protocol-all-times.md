# 早期动作方向同样本时间复核

预注册日期：2026-09-29。性质：冻结 checkpoint 的单卡离线复核；不训练、不仿真。

## 动机

先前动作方向探针在 H9 10K 的 `t=0.7` 得到正向差值，但不同时间点使用了不同
样本。该复核让每个样本在 `t=0.1/0.3/0.5/0.7/0.9` 全部计算，排除时间点与样本
构成不同造成的混杂。

## 设置

- 模型：backview SFT 与 H9-Fixed，分别为 5K 和 10K checkpoint。
- 每个 checkpoint：128 个 BS8 batch；每个 batch 的同一输入、动作和噪声遍历五个 t。
- 两模型共享样本、噪声和时间；中心化 7 维 action cosine 是主指标。
- episode 配对 bootstrap 2,000 次，报告每个 t 和 pooled 的 95% 区间。
- 不访问 teacher，不更新参数，不使用仿真成功率作为本实验指标。

## 判定

若 H9 相对 SFT 在 10K 的 `t=0.7` 同样本 cosine 区间仍严格高于 0，记录为
“10K 中间时间段的可复现机制信号”，并仅据此设计后续时间条件 ACL 训练；若区间
跨 0 或 5K/10K方向不一致，则关闭该路线，不改变训练时间采样。

该实验不能证明 benchmark 成功率提升，也不能区分 ACL 和 contribution 的因果作用。
