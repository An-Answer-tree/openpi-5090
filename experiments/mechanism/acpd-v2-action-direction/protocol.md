# ACPD-v2 早期动作方向诊断

预注册日期：2026-09-29。性质：冻结 checkpoint 的探索性离线机制诊断；
不训练、不仿真、不移动数据集或模型。

## 问题

H9-Fixed 与匹配 SFT 的训练 flow MSE 近乎重合，但 5K/10K 的任务成功率更高。
现有 ACL 损失将 teacher/student 的真实 7 维动作序列展平、中心化并单位化后比较
方向。检验 H9 是否也更接近真实 flow 目标的**中心化方向**，而非只在 MSE
中产生未见的细微差别。

## 固定设置

| 项目 | 设置 |
|---|---|
| 模型 | backview BS64 H9-Fixed 与 SFT；各自 5K、10K checkpoint 分别比较 |
| 数据 | fixed_dataset，原归一化统计；两模型用同一图像、动作、噪声和时间 |
| 输入 | BS8，各 128 batch；按样本轮流使用 flow time `0.1/0.3/0.5/0.7/0.9` |
| 资源 | 单卡冻结前向；不加载 teacher；5K/10K 两个普通单卡子任务串行 |
| 主指标 | 真实 7 维 action chunk 展平、逐样本中心化及单位化后，H9 与 SFT 相对真实 flow 目标的 cosine 差值 |
| 次指标 | 同样本 7 维 flow MSE 差值；五个时间点的方向差值只作描述 |
| 不确定性 | 各 checkpoint 按 episode 等权平均，2,000 次配对 episode 重采样，报告百分位 95% 区间 |

目标 flow 为 `noise - actions`。cosine 完全沿用 ACL 的 7 维、整段动作、
中心化口径，只是把 ACL 的 teacher 对照替换为真实 flow 目标。
两模型的每个分支共享同一输入；5K/10K 分开分析，不把不同训练运行合并为一条
连续轨迹。检查结果是否有限值，并核对相同点的 episode 数、样本数与 MSE。

## 判读

只有 5K 和 10K 的 H9−SFT 主指标区间均严格大于零，才称这两个早期点
一致支持“更接近真实动作方向”；若任一点跨零，则不作一致机制结论。
时间点子项没有多重比较校正，不据此挑选时间重采样策略。

这是训练集上的单次 noisy-action 离线拟合诊断，不是独立验证集，也不是
LIBERO 闭环成功率。即使方向改善，也不能单独证明 ACL 或 contribution
哪个组件造成改进；需等待正式 ACL-only 对照与推理注入消融。
