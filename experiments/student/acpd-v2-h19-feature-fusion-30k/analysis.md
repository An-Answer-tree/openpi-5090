# H9-Fixed 与 H19-FeatureFusion 比较

分析日期：2026-10-08。只复用已完成训练和全量验证，无新增训练或仿真。

## 实际设置

| 项目 | H9-Fixed | H19-FeatureFusion |
|---|---|---|
| 学生/教师 | backview / agentview+wrist | 相同 |
| 数据与初始化 | fixed_dataset；pi0.5 base | 相同 |
| 训练 | 4×5090，FSDP LoRA，physical global BS64，累积1，seed42 | 相同 |
| loss 权重 | flow/contribution/ACL = 1.0/0.2/0.5 | 相同 |
| 学习率 | warmup1000，peak2.5e-5，cosine decay_steps30000，end2.5e-6 | 相同 |
| 贡献预测 | layer10 hidden 预测两路1024维向量 | 相同 |
| 动作输出前的信息融合 | 两路预测相加，乘可学习标量，再加到最终hidden | 拼接最终hidden和两路预测，经3072→128→1024网络生成特征修正，加到最终hidden |
| 原动作输出层 | 保留，输出32维 | 相同 |
| 动作损失直接更新预测器 | 贡献输入使用stop_gradient，不经注入路径更新预测器；共享主干仍有动作梯度 | 相同；动作损失可以更新新增融合网络 |
| 新增融合网络参数 | 无 | 525,440 |

本文 H19 指当前特征融合方案，不是已放弃的32维动作修正头方案。
H19 不使用 H9 的标量gate，因此日志中的gate=0不是失效指标。

## 训练 loss

读取原H9训练129728和H19训练136345的完整0–30K日志。各有300个指标记录，
排除Step0后对齐299个记录点；解析指标均为有限值。动作监督loss均为32维flow MSE，
不是只对机器人实际使用的7维计算的 `student_task_loss`。
下表为日志记录点的算术均值，首窗口为100–4900步，随后每窗50个记录点。

| 步数窗口 | H9动作监督loss | H19动作监督loss | 相对差异 | H9加权贡献loss | H19加权贡献loss | H9加权ACL loss | H19加权ACL loss |
|---|---:|---:|---:|---:|---:|---:|---:|
| 0–5K | 0.037494 | 0.037457 | −0.098% | 0.105039 | 0.104988 | 0.028555 | 0.028532 |
| 5–10K | 0.027406 | 0.027388 | −0.066% | 0.069540 | 0.069548 | 0.020414 | 0.020398 |
| 10–15K | 0.024714 | 0.024674 | −0.162% | 0.061734 | 0.061712 | 0.018217 | 0.018187 |
| 15–20K | 0.022330 | 0.022332 | +0.009% | 0.055988 | 0.055968 | 0.016252 | 0.016244 |
| 20–25K | 0.020326 | 0.020322 | −0.020% | 0.051786 | 0.051814 | 0.014617 | 0.014609 |
| 25–30K | 0.018822 | 0.018798 | −0.128% | 0.048932 | 0.048908 | 0.013403 | 0.013377 |

相对差异为 `(H19−H9)/H9`。监督loss轨迹相关系数为0.999840，各窗口均值差异
不超过0.17%；贡献loss和ACL loss也几乎重合。加权贡献loss在两者总目标中都约占
59%–61%，这是标量目标占比，不是梯度占比或不利作用的证据。
日志指标只打印4位小数，微小差值不能作为优化改进依据。

| 25–30K指标 | H9 | H19 | 解释 |
|---|---:|---:|---|
| 总loss均值 | 0.081164 | 0.081078 | 几乎相同 |
| 预测贡献cosine均值 | 0.797180 | 0.796822 | 向量方向相似度；不是预测准确率 |
| 最后记录29900步的监督loss | 0.0184 | 0.0184 | 无更低训练误差证据 |
| 最后记录的预测贡献cosine | 0.7999 | 0.8002 | 无更好贡献预测证据 |

贡献监督使用归一化MSE。H19没有显示更快的flow收敛或更好的贡献预测。
训练MSE接近与仿真成功率不同可以同时发生；现有数据不能确定其机制，
也不能仅凭这些loss推断过拟合。

## 方案判断

| 决策 | 数据支持的判断 |
|---|---|
| 固定30K训练预算，哪个已测分数更高 | H19：60.10% 对58.00%，高2.10点；仍需区分观测值和稳定收益 |
| 哪个有更完整的主方案证据 | H9：早期SFT对照、5K训练期注入消融及5K–40K轨迹 |
| H19是否已证明更有效利用特权贡献 | 未证明；新增525,440参数，尚无相同网络但不输入贡献的训练对照 |
| 是否已提高最终成功率上限 | 两者均未证明。H9最高观测点35K为61.05%；SFT最高观测点60K为62.05%；H19只验证到30K |
| 当前建议 | 以H9为论文主方案，H19保留为融合改进候选；该建议不等于H9性能已被证明高于H19 |

H9相对SFT10K提高14.20点，配对95%区间[+11.90, +16.60]；
H9相对训练期去注入H13在5K提高2.55点，区间[+0.40, +4.70]。
这些结果支持H9当前的早期作用证据，但不能转用来证明H19新融合结构的收益。

下一决策点为已提交的H19 35K续训139791及其全量验证；本次查询仍为Priority排队。
35K结果未产生，不与H9 35K直接排名。若其结果值得转向H19，再用保持相同融合
网络、损失和训练设置但将贡献输入置零的对照检验收益来源；该对照已有开关，未运行。
本次不提交新任务，不更改现有训练、评测或checkpoint。
